小说协作团队 Agent

给出一个故事想法，围绕写作目标分工、试写、审读，再把问题交回对应角色继续修改。

任务推进 · 五位角色 · 共享文档 · 作者确认

这个 Agent 要做什么？

帮助作者把零散想法推进为可修改的章节。设计围绕一个持续的写作任务展开：判断缺少什么、由谁处理、交付什么，以及什么时候需要作者决定。

所有确定的讨论放在同一份共享文档里，作为后续设定、写作和审读的共同依据。

Agent 怎么推进任务看一次写作演示Agent 优化方向

接到任务之后，怎样继续往下做？

角色的 Skill 规定“这项工作怎么做”；Agent 的协作设计把目标、资料、角色和反馈串起来，决定每一步交给谁、做到哪里，以及下一步如何接续。

任务示例

围绕“镇馆之宝是假的”，完成第一章试写并审读。

需要交付：世界规则、人物档案、章节卡、试写片段，以及带原文依据的审读意见。

  1. 01 / 读取

    理解目标与已有资料

    读取共享文档中的已定设定、人物和当前进度，识别信息缺口；需要作者判断的内容先提出问题。

  2. 02 / 分工

    把问题交给合适的角色

    世界规则交给法棍，人物动机交给可颂，情节结构交给吐司。各自带着任务与相关资料开展工作。

  3. 03 / 执行

    把确定内容写成正文

    贝果依据章节卡、人物档案和文风要求试写，同时登记新细节，供后续确认与核对。

  4. 04 / 检查

    把正文与依据逐项对照

    黑麦检查设定、人设与情节，引用问题原句，区分必改、建议和偏好，并指出需要谁处理。

  5. 05 / 反馈

    按问题回到对应环节

    规则冲突回到法棍，人物问题回到可颂，结构问题回到吐司。涉及创作决定时等待作者确认。

  6. 06 / 接续

    确认后修改，再次审读

    确定的讨论汇入共享文档，贝果据此改稿，黑麦复审。未解决的问题进入交接卡，成为下一轮起点。

审读发现冲突 → 转交负责人 → 作者确认 → 修改正文 → 再次审读

任务背后的五位协作成员

各自有明确职责，交付物会成为下一位成员的输入。

1 / 世界规则

法棍

世界观设定师

搭建时代、制度、命名和特殊规则，检查设定是否自洽。

交付：《世界观设定集》

2 / 故事里的人

可颂

人物设计师

明确人物想要什么、害怕什么、怎样说话，以及不会越过的底线。

交付：《人物档案》

3 / 故事路线

吐司

大纲设计师

安排冲突、伏笔、节奏与章节目标，逐步细化接下来要写的部分。

交付：《大纲》与章节卡

4 / 落到文字

贝果

执笔者

按作者确认的文风写正文，登记新增细节和偏离大纲的地方。

交付：正文、摘要与新增记录

5 / 检查与反馈

黑麦

审读编辑

核对设定、人设和情节，引用原句，按轻重提出意见。

交付：审读意见与转交单

先读资料，再问问题

开工前读取共享文档与交接记录，根据任务需要澄清目标、补足信息，优先解决影响推进的问题；已确认的内容不重复询问。

提议和定稿分开

引用已定内容时说明来源；自己补充的写成“新提议”，真实知识拿不准时标为“待考证”。

发现问题，转给负责人

审读不擅自改写世界观或人设，先给出问题位置与转交单。每段工作结束，留下下一轮能接续的交接卡。

人在哪里参与？ 作者确认设定与人物、决定关键转折和结局、选择是否采纳审读意见。AI 提供方案和修改依据，确认后的内容才进入共享文档。
共享文档怎样让不同角色接上工作？

所有确定的讨论放在同一份共享文档里，按内容分区，供后续角色查阅。

世界规则与人物档案
收录法棍、可颂的已确认内容，后续角色据此核对命名、规则和人物行为。

大纲与伏笔追踪
收录吐司的章节安排，贝果据此写作，黑麦核对目标与伏笔。

文风指南与章节摘要
保留已确认的写作风格、章节进展与新增细节，支持长篇接续。

决定与交接记录
写清已完成、作者已确认、待定问题和下一步。

被诬陷偷窃的实习讲解员，在闭馆夜里摔裂一面铜镜。镜中的女官告诉她：展柜里即将拍出天价的“国宝”，才是假的。距离拍卖只剩三天，两人必须揭穿真相。

法棍：入职第一轮提问

法棍说： 我先读了知识库，目前只有作者给的一段故事设定，还没有《世界观设定集》。这一轮只问三个会直接影响设定的问题，每个都附了选项，选字母就行。

  1. 时代参照：女官来自的朝代，用真实朝代还是架空？
    • A. 真实朝代（如唐代），质感强，但考据要求高
    • B. 参照唐代的架空朝代，保留风物，名称和制度可以自由调整
    • C. 完全架空
  2. 镜中人的规则：她能离开镜子多久？有没有代价？
    • A. 只能在闭馆后出现，天亮前必须回到镜子附近
    • B. 可以一直在外面，但每用一次能力，镜面就多一道裂痕，裂满就会彻底消失
    • C. 你来定，我出 2～3 个方案
  3. 拍卖的合理性：国有博物馆的馆藏文物一般不能买卖（具体法规【待考证】），这里需要一个说得通的理由。你倾向哪种？
    • A. 那面"国宝"是馆长私人借展的藏品，展期结束后送拍
    • B. 这是一家私人博物馆，馆藏归老板个人所有
    • C. 先不管，后面再补

以后再问：馆里其他古物会不会也醒来；人名和地名的风格偏好。

作者的回答（演示用虚构）：1 选 B，2 选 B，3 选 A。

先确认约束，再扩展世界

任务与输入输入：故事设定。输出：会影响世界规则的问题，附选项。

判断与行动作者在演示中选择架空朝代、使用能力会增加裂痕、私人借展藏品。其余问题暂不展开。

交接状态这些回答只属于本次虚构演示，不是读者正在作出的选择。

可颂：主角简化档案

可颂说： 根据故事设定和作者给法棍的回答，先给两位主角建简化档案。《世界观设定集》还在整理中，涉及朝代制度的地方我标了【新提议】，等法棍确认。

林小满（现代）

  • 基本信息：23 岁，博物馆实习讲解员，入职三个月
  • 性格：表面随和、怕麻烦；被逼到墙角时嘴硬、记仇
  • 内核：想要留下来转正；真正需要的，是相信自己的判断，而不是一直等别人认可
  • 说话方式：短句，爱自嘲，一紧张就背展品说明。示例："青铜，八瓣菱花形，直径十八点五厘米……别看我，我一紧张就背词。"
  • 行为准则：不会当众哭；不会出卖帮过她的人
  • 与沈照的关系：互相不信任，却只能互相依靠

沈照（镜中人）

  • 基本信息：自称前朝的掌镜女官【新提议："掌镜"这个官职名需要法棍确认是否符合制度设定】
  • 性格：冷静、傲慢，习惯发号施令；对现代世界很好奇，但死不承认
  • 内核：想证明自己才是真的那面镜子；最怕再一次被遗忘在库房里
  • 说话方式：文白夹杂，句子短而断然。示例："你摔的这面才是真的。展柜里那面，连镜钮都铸反了。"
  • 行为准则：从不撒谎，但会选择不说；绝不向馆长低头

待定：沈照为什么千年后才醒来。这一点会影响主线，转交吐司。

新提议不能悄悄成为定稿

贝果说： 按吐司的章节卡和可颂的档案，试写了第一章的开头和结尾两段，中间先略过。文风按短剧节奏处理：短段落，对白推进，每段结尾有落点。

馆长周望山把平板转过来，监控画面停在她弯腰的那一秒。整个讲解部的人都在看她。

"讲解器？"周望山笑了一下，又回头看了一眼展厅尽头那座单独打光的展柜，"明天不用来了。今晚把你那片区收拾干净，算是给你留个体面。"

镜面裂开一道细缝。

她蹲下去，手还没碰到镜子，就听见头顶有人开口："手拿开。"

"你……是谁？"

"沈照。"女人抬了抬下巴，指向展厅尽头那座单独打光的展柜，"那面被你们称作国宝的，镜钮铸反了，是假的。你方才摔的这面，才是真的。"

黑麦：分级审读

黑麦说： 开头几行就把小满逼到了墙角，结尾的裂痕倒计时很有力，短剧节奏是对的。最需要处理的有两点：铜镜"怎么才会裂"的规则还没对齐；结尾钩子和章节卡有偏差。

做得好的地方

  • "像在看一件放错位置的展品"：一句话立住了沈照的傲慢，也和博物馆的场景呼应。

Agent 以后可以怎样优化？

让任务调度、资料调用与审读修订衔接得更完整。以下是后续规划，尚未实现。

让任务自动分派与接续

根据任务状态自动选择下一位角色，携带相关文档与上下文，记录“待作者确认 / 待改稿 / 待复审”。涉及设定、人物或结局的重大变更，仍停下来等作者决定。

验证：减少重复转述和漏接任务，检查角色是否越界。

让共享文档有版本和来源

把已定设定、新提议和待考证内容分开保存。修改后提示受影响的人物、章节与伏笔；作者确认后再同步给各角色，并可回看旧版本。

验证：检查旧规则是否误用、关键决定是否可追溯。

按项目建立参考知识库

整理作者指定的范文、叙事方法、历史与器物资料，检索时带上出处与适用范围。真实资料、虚构设定和作者偏好分开，不把写作框架当作必须套用的模板。

验证：核查引用是否存在、考据是否可靠、文风是否符合作者要求。

增加独立审读与长篇评估

尝试不同模型或人工编辑复核；将设定、人设、时间线与伏笔的冲突作为检查对象，结合作者对人物声音和阅读体验的判断。

验证：在留出章节上记录漏检、误报和修改采纳情况，同时评估运行成本。

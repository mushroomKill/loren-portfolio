轻度心理学习与练习skills

给出一个主题，AI 按约定的要求起草三天的讲解、练习题和答题反馈。

这里的 skill 是什么？一份可反复使用的 AI 写作说明书，规定课程怎么安排、题目怎么出、反馈怎么写，以及写完后检查什么。

给它一个主题，会得到什么？

使用示例
例如，告诉 AI

“帮我写一周关于‘认知解离’的心理练习，分三天。”

有参考书或资料时，也可以一起提供。
  1. 1

    先列出三天分别讲什么

    AI 起草大纲，写作者确认内容方向后，再展开写。

  2. 2

    每天写讲解、题目和反馈

    按说明书安排内容；答对要解释原因，答错也要给出温和、具体的反馈。

  3. 3

    按清单检查，标出需要核对的地方

    检查题目是否缺答案、漏反馈，概念是否有出处；没有依据的内容标为“待核”。

  4. 4

    交出可审阅的课程草稿

    包含三天正文、供 App 使用的题目数据，以及需要写作者核对的出处清单。

写作者可以修改草稿；心理学内容仍需专业人员审核。

认知解离 · Day 1题目示例

想法就像漂来的纸条，你可以读一读，也可以让它继续漂走。

下面哪一句，说明你和想法之间已经拉开了一点距离？

  1. 我肯定会搞砸，还是别报名了
  2. 别想了别想了，这种想法太消极了
  3. 我注意到，我脑子里又冒出了“我会搞砸”这个想法 ✓ 正确
  4. 我得找出证据，证明自己不会搞砸

选 B 时 先理解，再指出差别

想把消极的想法推开，是很自然的反应。只是越告诉自己“别想”，它往往越会冒出来。解离不是赶走想法，而是换个距离看它。

选 C 时 解释为什么对

对啦！“我注意到……这个想法”让你从纸条里走了出来。想法还在，但它变回了一张纸条，而不是一个命令。

规划方向

当前展示的是 skill 规则与已有样例，网页没有接入模型。下一步可以把它做成供内容写作者使用的课程助手。

把写作步骤串成课程助手

输入主题后，依次完成大纲、三天草稿、格式检查与审阅交付，减少手动来回复制内容。

输入主题 → 人确认大纲 → 生成与检查 → 人审核

适合做成 Agent 吗？

可以从固定流程开始：模型负责草稿，已有校验脚本检查结构，保留大纲确认和最终审核两个环节。固定步骤并不要求先做 Agent。

需要助手自行选择参考资料、调用校验工具并根据错误修改时，再加入 Agent。为修改设置次数上限，保留版本与检查记录，遇到不确定的内容交给写作者处理。

定位仍是辅助课程创作。内容经专业人员审核后再使用，不直接把自动生成的草稿作为心理咨询或治疗建议交给用户。

让概念与引用更有据可查

先建立经过审核、可使用的知识资料库，让课程中的概念能回到具体出处。

整理资料 → 检索相关段落 → 带出处生成 → 复核引用

RAG 可以帮什么忙？

RAG 就是生成前先查资料。按主题与流派检索相关知识卡，保留书名、章节、页码或链接，再把这些资料交给模型写作；检索不到时明确标记“待核”。

检索到一段文字不等于概念就正确。仍需检查引用是否支持原句、是否混用了不同流派，以及练习题是否有歧义。

先处理现有 29 条待核概念，再增加由专业人员审核的样例与独立复核。对比引用准确性、题目歧义和风险表达，之后再考虑扩大主题范围。
